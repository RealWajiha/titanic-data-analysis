# 🚢 Titanic Dataset — Data Analysis Using Python

## 📌 Project Overview
This project focuses on analyzing the Titanic dataset using Python to discover meaningful patterns, statistics, and relationships between passenger information and survival outcomes.

The analysis uses **Pandas, NumPy, Matplotlib, and Seaborn** to explore the data and present insights through visualizations.

## 🎯 Objectives
- Calculate basic descriptive statistics.
- Identify maximum and minimum values.
- Compare survival rates across passenger groups.
- Analyze passenger age and ticket fare distributions.
- Explore correlations between numerical variables.
- Create visualizations to communicate findings.
- Identify at least three important insights from the dataset.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

### 1. Basic Statistical Analysis
Calculated mean, median, standard deviation, minimum, maximum, and quartiles.

### 2. Survival Analysis
Examined passenger survival counts and overall survival percentages.

### 3. Gender-Based Comparison
Compared survival rates between male and female passengers.

### 4. Passenger Class Analysis
Investigated survival rates across passenger classes.

### 5. Age and Fare Distribution
Explored passenger ages and ticket fares using statistical summaries and histograms.

### 6. Correlation Analysis
Used a correlation matrix and heatmap to explore relationships between numerical variables.

### 7. Data Visualization
Created charts using Matplotlib and Seaborn to present the findings clearly.

## 🔍 Key Findings
The notebook identifies important patterns, including:

1. Differences in survival rates between male and female passengers.
2. Variations in survival rates across passenger classes.
3. Patterns in passenger age and ticket fare distributions.
4. Relationships between selected numerical variables.

*Exact results and percentages are available in the notebook outputs.*

## ▶️ How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/RealWajiha/titanic-data-analysis.git
   ```

2. Navigate to the project folder:
   ```bash
   cd titanic-data-analysis
   ```

3. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

5. Open `Task_02_Data_Analysis.ipynb` and run the cells.
